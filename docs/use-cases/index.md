# Use Cases

Illinois Chat is a platform; the assistants built on it are where it shows its value. This section documents specific deployments in depth: what they contain, which tools they add, and what to know before using them.

- :material-sprout: **[CropWizard](cropwizard/index.md)** — the agricultural assistant for farmers, extension agents and researchers, built on curated extension and research documents, with tools for pest detection and seasonal characterization of field trials.

More use cases will be added here as they are documented. If you run an assistant on Illinois Chat that others would benefit from reading about, contact support using the address in the page footer.
